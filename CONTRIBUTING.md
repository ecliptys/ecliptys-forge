# Contributing to Ecliptys Forge

Thanks for contributing to Forge!

## Development workflow

1. Create or select an issue.
2. Create a branch from `main`.
3. Make focused changes.
4. Add or update tests when applicable.
5. Open a pull request.
6. Address review feedback.
7. Merge after approval and validation.

## Branch naming

Use descriptive branch names:

- `feature/...`
- `fix/...`
- `docs/...`
- `refactor/...`
- `chore/...`

Examples:

- `feature/repository-scanner`
- `fix/java-parser`
- `docs/architecture-overview`

## Commits

Use clear, descriptive commit messages.

Examples:

- `feat: add repository scanner`
- `fix: ignore generated files`
- `docs: explain repository analysis`
- `test: add scanner integration tests`

## Pull requests

Keep pull requests focused and explain:

- what changed;
- why it changed;
- how it was validated;
- important design decisions.
